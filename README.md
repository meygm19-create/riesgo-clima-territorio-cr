# Riesgo, clima y territorio

Página interactiva del curso **GF-2510 · Geografía Regional de Costa Rica**, Universidad de Costa Rica.

## Publicar con GitHub Pages

1. Cree un repositorio nuevo en GitHub.
2. Extraiga este archivo ZIP.
3. Suba **todos los archivos extraídos** a la raíz del repositorio.
4. En GitHub, abra `Settings` → `Pages`.
5. En `Build and deployment`, seleccione `Deploy from a branch`.
6. Seleccione la rama `main`, la carpeta `/ (root)` y guarde.
7. Espere unos minutos. GitHub mostrará la dirección pública de la página.

## Acceso

La clave utilizada por la actividad es `geocr26`.

> Nota: la clave está implementada en JavaScript del lado del navegador. Sirve como barrera sencilla para el curso, pero no constituye un sistema seguro de autenticación. En un repositorio público puede ser consultada en el código fuente.

## Archivo principal

GitHub Pages abre automáticamente `index.html`. No es necesario instalar programas, dependencias ni ejecutar una compilación.
